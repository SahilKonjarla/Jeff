# Installed active-work lifetime scenarios

Process-backed owner-loss/client/queued-work/Git lifetime fixtures and their support programs. Captured owners, worker leases and teardown are part of the scenario; saved PID values are not replacement control authority.

These tests can launch native processes and inject faults. Run only an explicitly approved finite selection against owned outside-Git fixtures and the intended installation; never replay historical handoffs or default state. Source assertions are not independent kernel/process census. See [acceptance guidance](../README.md) and [suite boundaries](../../README.md).
