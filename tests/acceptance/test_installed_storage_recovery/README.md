# Installed storage recovery

Installed publication and transaction-recovery scenarios distinguish original owned journal/proof recovery from unsupported residue. Fault injection at a Python boundary is not universal physical power-loss or disk-failure coverage.

Native/fault setup requires explicit finite authority, genuine captured ownership and private outside-Git fixtures. Preserve failed/unknown evidence; no rekey, DB reset, broad cleanup or historical marker reuse.
