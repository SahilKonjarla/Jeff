# Prepared-input integration

Preparation and integrity checks exercise bounded literal-file snapshots, excluded paths, no-follow filesystem policy and immutable reviewed bytes. Temporary filesystem behavior is real; it does not prove Docker execution, universal secret discovery or adversarial race immunity.

Use synthetic public inputs in approved private outside-Git arenas. Do not import real credentials/customer files or reset failed snapshots to repeat a scenario.
