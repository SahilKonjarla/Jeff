# Project dispatch integration

Registration and deterministic Git-question routing through application/dispatch adapters and controlled repository fixtures. Preserve project-root identity, result correlation and failure semantics; no provider or general command execution is implied.

Temporary Git/registration writes must stay in approved disposable outside-Git fixtures, not the source checkout/default user state. Controlled adapters are distinct from installed/native RPC evidence. See [dispatch contracts](../../../src/jeff/application/dispatch/README.md), [integration policy](../README.md) and [suite map](../../README.md).
