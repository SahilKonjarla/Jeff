# Runtime path inspection

Import safety, metadata policy and sampling checks exercise bounded no-follow identity/path observations. Sampling and model agreement are not full host isolation, atime invariance or complete filesystem-race proof.

Use approved owned outside-Git fixture paths; do not inspect default credential/state directories or repair unsafe entries. Read-only observations never supply mutation authority.
