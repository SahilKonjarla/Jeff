# Native ownership state

Birth identity, namespace ownership and endpoint preparation/publication fixtures validate locks, signed proofs and unsafe residue refusal. Cases may combine controlled metadata with real native identity/socket setup; select and authorize them explicitly.

A missing PID/socket or free lock alone never authorizes cleanup. Preserve unknown/foreign state; no stored PID signalling, rekey/reset or automatic adoption.
