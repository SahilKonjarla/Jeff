# Infrastructure — tier2

Owns concrete project files, private runtime state, native/authenticated IPC, lifecycle, SQL, committed event delivery and diagnostics. Depends inward on application/domain plus stdlib/PyYAML; no bootstrap/client policy or sibling integration calls. M02 is delivered/accepted on Mac; general execution isolation is not proved. M03 selects declared Docker jobs, not a general native sandbox rewrite; an internal controller/transport exists, but no production-wired container executor is delivered. Linux Jeff client/runtime compatibility is out of scope. [Tier map](../README.md).

- Layout selection uses explicit trusted host inputs/overrides and known Darwin base aliases, not arbitrary symlink resolution or temp write probes. - `Ownership` is a real flock description. Exec inherits the same description; parent closes only its copy, never `LOCK_UN`. Stable empty anchor/key persist through stop. Child/helper ownership cannot be recreated from a PID, pathname or an old metadata snapshot.

## Guarded output collector — memory only

`GuardedOutputCollector(manifest.profile.output_bytes)` implements the existing attach sink. Retained stdout+stderr, including notices and visible escapes, share the manifest cap≤1MiB. Each stream and observed-arrival line holds≤8192 raw bytes including LF; the deferred raw window holds≤32768 bytes with an equally bounded channel-tag buffer. Release waits until every intersecting frame is classified. UTF-8 is validated per stream, never by decoding arbitrarily interleaved channels. Pending raw/tag byte storage is bounded separately from retained text; these counters do not claim a measured Python RSS bound or secure memory erasure.

Fixed case-insensitive ASCII policy recognizes credential assignments (exact known keys or underscore suffixes), auth/Bearer forms, credential-bearing URLs and PEM private-key indicators. Known assignments include password/passwd/token/secret/credential(s), API/access/private keys and auth/authorization; hyphens normalize only for classifier matching. This is pattern-only, not universal secret detection: unlabelled, encoded or obfuscated values may not match. A detection, overlong/deferred frame or invalid per-stream UTF-8 withholds the unresolved frame **and all remaining output on both streams**; earlier classified prefix may remain. Saturating source-byte counts and finite transport draining continue; guard/cap activation does not itself stop the job or imply unknown execution.

Text retains LF but escapes other controls, bidi and non-ASCII to visible ASCII. Render it as untrusted plain text, never interpret escapes/markup/instructions again. Truncation/guard notices fit inside even tiny configured caps. Output after truncation is discarded, not certified free of sensitive content. Both actual EOFs are required for normal `seal()`; explicit abort drops unresolved frames. The immutable `DockerOutputSnapshot` describes sanitized bytes and EOFs, not controller/identity/exit/cleanup confirmation or permission to finish a claim. The collector performs no I/O or persistence. The default30-day age remains; separately approved SQL output/completion and capacity retirement now exist as described below. Explicit internal composition is now present but not activated by daemon/CLI/RPC.
